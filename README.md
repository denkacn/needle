# Needle

Needle is a fast, minimal log viewer for people who need to open local log files, follow live updates, and find the important lines without setting up servers or databases.

It is inspired by BareTail, but built as a modern desktop app with tabs, highlights, bookmarks, triggers, themes, and smooth work with large files.

## What It Does

- Opens large local log files quickly.
- Keeps the interface responsive while reading big files.
- Follows files as they grow in real time.
- Handles file truncate and log rotation.
- Opens several log files in tabs.
- Searches text with next and previous navigation.
- Filters visible lines and hides noisy lines per tab.
- Highlights important patterns globally or only for the current tab.
- Marks lines with bookmarks and jumps between them.
- Watches trigger patterns in new log lines and marks matches automatically.
- Shows a mini-map with bookmarks, triggers, errors, warnings, and search matches.
- Supports dark and light themes.
- Lets you choose font, font size, text color, and other display settings.
- Saves recent files and window layout.
- Can export and import settings for moving to another PC.

## Good For

Needle is made for local log inspection:

- backend logs;
- game server logs;
- desktop app logs;
- service logs;
- plain text diagnostic files;
- quick troubleshooting on another machine.

## Not Trying To Be

Needle is not Kibana, Seq, Grafana, or a log database. It does not require importing logs, running a service, or configuring storage. Open a file, inspect it, and keep moving.
